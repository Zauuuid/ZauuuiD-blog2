# إعادة تصميم موقع ZAUUUID

## الهدف

إعادة بناء الموقع الحالي باللغة العربية وبأسلوب هادئ ومختصر، مع تعريف واضح بصاحب الموقع وعرض مشاريعه وخبراته ومهاراته.

## التسليم

- [x] مراجعة المستودع والعمل على الفرع `redesign/technical-dossier-v1`.
- [x] اعتماد ألوان طبيعية هادئة وإزالة الصورة الشخصية.
- [x] بناء صفحات عربية باتجاه RTL باستخدام Cairo.
- [x] ترتيب المشاريع والخبرة والمهارات من المعلومات الموثقة.
- [x] ضبط العرض للجوال وتبسيط الصفحة وصفحة دراسة المشروع.
- [x] تحديث تصميم Figma بالعربية لسطح المكتب والجوال ولوحة الألوان.
- [x] إنهاء التحقق النهائي من الجوال والصفحات وبناء الإنتاج.
- [ ] نشر معاينة Vercel: تعذر لأن صلاحية الموصل لا تسمح بإنشاء مشروع أو نشر ضمن الفريق.

عدم دمج الفرع إلى `main`.
